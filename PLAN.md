# План приложения — дневник тренировок

Статус: первая рабочая версия реализована по одобренному эскизу. Проверку приложения пользователь выполняет самостоятельно; тестирование агентом исключено по его просьбе.

## Задача

Удобно записывать на телефоне результаты каждого подхода в зале, видеть предыдущие результаты и отслеживать изменения по упражнениям и тренировкам. При выборе упражнения иметь доступ к подсказкам по технике и настройке тренажёра.

## Подтверждённые решения

- Один пользователь, один телефон.
- Данные можно хранить локально; регистрация и синхронизация между устройствами не нужны.
- Мобильный веб-интерфейс. Отдельное нативное приложение не требуется.
- Для первой версии допустима работа с интернетом. Полноценный офлайн-режим не входит в обязательный объём.
- Есть основа тренировок, но упражнения часто меняются по ходу занятия.
- Формат занятий — full body. Обычно три подхода по 8–12 повторений; пользователь описывает выполнение до отказа.
- Основной телефон и браузер — iPhone, Safari.
- Группы: ноги, грудь, спина, плечи (включая отдельные пучки), трицепс, бицепс, пресс.
- Нижняя навигация: три крупные кнопки «Дашборд», «Тренировка», «Настройки».
- Экран тренировки — вертикальный список крупных раскрывающихся групп мышц. Переключатель групп в виде вкладок не нужен.
- Карточку «В прошлый раз» с предыдущими весами и повторами сохраняем внутри каждого упражнения.
- Дашборд должен поддерживать сводку за месяц и за выбранный день.

## Основа full body

Это описание пользовательского сценария, а не назначение программы тренировок.

| Блок | Известные варианты | Что уточняется по ходу наполнения каталога |
| --- | --- | --- |
| Ноги | Присед, жим ногами в тренажёре | Вариант приседа и конкретный тренажёр |
| Грудь | Жим лёжа, жим от груди в тренажёре | Оборудование и настройки |
| Спина | Упражнение выбирается пользователем | Конкретные тяги и тренажёры |
| Плечи | Основное упражнение и упражнения на отдельные пучки | Названия и число упражнений |
| Трицепс | Упражнение выбирается пользователем | Конкретный вариант |
| Бицепс | Упражнение выбирается пользователем | Конкретный вариант |
| Пресс | Упражнение выбирается пользователем | С весом или без внешней нагрузки |

- В шаблоне можно хранить предпочтительное упражнение и менять его в текущем занятии. Для первой версии достаточно обычного списка упражнений и выбора замены по группе мышц.
- Создавать по три незаполненных подхода, отображать ориентир 8–12 повторов. Разрешать любое фактическое число подходов и повторений, а не ограничивать ввод этим диапазоном.
- Введённые либо подставленные значения сами по себе не означают выполненный подход.
- Разные упражнения имеют независимую историю. Замена приседа жимом ногами не переносит вес и рекорды одного упражнения в другое.
- Замена упражнения с уже записанными подходами должна сохранять выполненную работу в этой тренировке; новое упражнение добавляется отдельно.
- Отметку «До отказа» можно добавить как необязательный признак подхода, если она окажется полезной. Не заполнять её автоматически и не предлагать автоматическое увеличение нагрузки на основании одного занятия.

## Предлагаемый состав первой версии

### 1. Запись тренировки

- Начать пустую тренировку, тренировку из шаблона или повторить прошлую.
- Добавить, заменить, переставить или пропустить упражнение. Изменение текущей тренировки не переписывает шаблон автоматически.
- Для каждого подхода записать вес и число повторений.
- Рядом показать подходы из предыдущей завершённой тренировки для этого упражнения и выбранного тренажёра.
- Подставлять в новый подход предыдущие значения, но считать подход выполненным только после явного подтверждения.
- Сохранять введённые данные по мере редактирования; продолжать незавершённую тренировку после закрытия страницы.
- Добавлять заметки к упражнению и тренировке.
- Завершать тренировку, исправлять прошлые записи и добавлять тренировку задним числом.

### 2. Упражнения и тренажёры

- Небольшой стартовый каталог на основе реальных упражнений пользователя.
- Поиск, избранное, создание своего упражнения.
- Различать упражнение и используемый тренажёр, если у упражнения есть несколько вариантов оборудования.
- Хранить заметку о настройке оборудования, например положение сиденья.
- Явно показывать способ записи веса: общий вес, вес одной гантели или другое обозначение, если это потребуется для выбранных упражнений.
- Не смешивать разные варианты оборудования в графике автоматически.

### 3. Подсказки по технике

- Открывать карточку из каталога или текущего упражнения.
- В карточке: настройка, последовательность выполнения, типичные ошибки и изображение либо ссылка на видео.
- Подготовить материалы из проверяемых источников для стартового каталога, указать источники.
- Для созданного пользователем упражнения разрешить собственную заметку и ссылку; не создавать автоматически непроверенную инструкцию.

### 4. Дашборд, история и прогресс

- Список завершённых тренировок по датам и подробности каждой тренировки.
- История подходов выбранного упражнения с учётом варианта оборудования.
- Переключатель «Месяц / День», выбор месяца или конкретной даты.
- За месяц: количество тренировок, подходов и повторов; график рабочего веса выбранного упражнения; список завершённых тренировок с переходом к дню.
- За день: количество упражнений, подходов и повторов; распределение подходов по группам мышц; подробные результаты каждого упражнения.
- График веса с доступными рядом значениями повторений. Основной вариант — линия с точками; столбцы можно рассмотреть как альтернативное оформление.
- Рабочий вес на графике — максимальный вес выполненного подхода в данном упражнении за занятие; при равном весе показывать подход с большим числом повторов. Повторы остаются видимыми, поскольку один рост веса не описывает весь результат.
- Распределение подходов по группам показывает объём выполненной работы, а не «процент качества» занятия.
- Сравнение с предыдущей тренировкой без сворачивания всех показателей в один условный процент.
- История находится внутри дашборда; каталог упражнений доступен из экрана тренировки при добавлении и замене.
- Незавершённые тренировки не включать в итоговую статистику.
- День или месяц без тренировок показывать как пустой период, без выдуманных точек на графике.

### 5. Шаблоны

- Сохранить набор и порядок упражнений под своим названием.
- Создать шаблон из завершённой тренировки.
- При запуске копировать состав шаблона в текущую тренировку; фактические результаты остаются отдельными записями.
- Изменение или удаление шаблона не меняет историю.

### 6. Хранение данных

- Локальная база в браузере как основное хранилище.
- Экспорт и восстановление резервной копии в первой версии: локальная история зависит от сохранности данных браузера.
- При импорте сначала проверять файл; не перезаписывать текущую историю молча.
- Для опубликованной версии использовать постоянный адрес сайта, поскольку данные браузера привязаны к адресу.
- Не показывать успешное сохранение, если запись в хранилище не удалась.

### 7. Настройки

- Мой шаблон: состав и порядок упражнений full body.
- Количество подходов по умолчанию для новых упражнений; стартовое значение — три.
- Единицы веса — килограммы в первой версии. Для гантелей явно подписывать, что вводится вес одной гантели.
- Оформление: системная, светлая или тёмная тема.
- Данные: экспорт истории, восстановление из файла, дата последней резервной копии.
- Настройки темы и количества подходов, экспорт и восстановление реализованы в рабочей версии.

## Мобильный интерфейс

- Нижняя навигация: «Дашборд», «Тренировка», «Настройки». Кнопки крупные, с подписью и иконкой.
- На экране тренировки подряд идут ноги, грудь, спина, плечи, трицепс, бицепс и пресс.
- Свернутый блок показывает название группы, выбранное упражнение или число упражнений и количество выполненных подходов.
- Раскрытый блок показывает упражнения, прошлые результаты, текущие подходы и замену упражнения.
- При сворачивании и переходе между основными экранами введённые значения сохраняются.
- Предложение для удобства: по умолчанию открывать один блок за раз; в эскизе можно сравнить этот режим с несколькими открытыми блоками.
- Крупные зоны нажатия, цифровая клавиатура для веса и повторений, минимум обязательного ввода.
- Прошлые результаты доступны рядом с текущими подходами.
- Черновик ввода не теряется при открытии подсказки по технике.
- На iPhone проверить отображение с открытой клавиатурой, ввод дробного веса, безопасные отступы и возврат после блокировки экрана.
- Добавление на главный экран телефона — желательное удобство, отдельное от полноценной работы без интернета.

## Возможные следующие функции

- Таймер отдыха.
- Личные рекорды с понятным правилом сравнения веса и повторений.
- Отметка субъективной сложности подхода.
- Целевые веса и повторы в шаблоне.
- Замеры тела.
- Офлайн-режим и синхронизация, если появится такая потребность.

## Порядок работы

1. Дизайн трёх экранов согласован.
2. Запись тренировок, IndexedDB, возобновление черновика и редактирование истории реализованы.
3. Дашборд использует завершённые тренировки пользователя; демонстрационных записей в рабочей версии нет.
4. Стартовый каталог, инструкции с источниками, шаблоны и резервные копии реализованы.
5. Публикация приложения и передача пользователю для самостоятельной проверки на iPhone/Safari.

## Открытые вопросы

- Точные упражнения на спину, плечи, руки и пресс можно уточнить при наполнении каталога; они не блокируют проектирование экрана записи.
- Поддержать внешний вес и упражнения без внешней нагрузки; необходимость учёта противовеса уточнить отдельно.
- Сохраняем одобренное спокойное зелёное оформление. Рассматриваем обновлённую структуру трёх экранов.
- Стек: HTML, CSS и JavaScript без сторонних зависимостей; локальное хранение IndexedDB; статическая публикация через Sites.
